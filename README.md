[GitHub Pages](https://mrrodiongrigorev.github.io/ahj-sse-dashboard/)

[Backend on Render](https://ahj-sse-dashboard.onrender.com/)

```bash
npm install
npm start
```

Frontend: `http://127.0.0.1:8082`. Backend: `http://127.0.0.1:3001`.

Для Render: Root Directory — `backend`, Build Command — `npm install`, Start Command — `npm start`.
После создания Render-сервиса добавьте его HTTPS-адрес в GitHub Actions variable `API_URL`.
